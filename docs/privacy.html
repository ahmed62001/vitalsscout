Privacy Notice

Effective Date: November 23, 2026

1. Static Storefront & Zero Tracking Cookies

This static storefront is hosted on GitHub Pages with no backend server. VitalsScout does not install third-party ad pixels, behavioral analytics cookies, or cross-site trackers, makes zero outbound blockchain or API requests from your browser (`connect-src 'none'`), and does not use browser localStorage as an order or payment database. The request brief builder runs strictly inside your browser until you copy and email your brief privately to vitalsscout@proton.me (the mailto:vitalsscout@proton.me link carries zero query parameters so your form inputs are never embedded in URLs).

2. Client Confidentiality & No Public Paid-Order Exposure

Our official dedicated private intake and customer contact channel is vitalsscout@proton.me. Paid orders, customer website URLs, email addresses, private contact handles, Order IDs, wallet addresses, and transaction hashes are never submitted through public GitHub Issues or stored in public repositories. Operator-maintained order and verification records are stored locally with restrictive filesystem permissions and excluded from Git commits. Paid deliverables and repository/staging reviews are handled privately for the commissioning client. Free 1-page snapshots may be requested privately via vitalsscout@proton.me or via the sanitized public template only when using publicly shareable URLs without private personal data.

3. Manual Payment Security

USDT (BEP20 on BNB Smart Chain) is the only accepted payment method. Payment instructions are issued manually only after private request acceptance, and payment verification is performed manually by the operator (the browser never verifies or marks payments as Paid). VitalsScout never collects, handles, or stores banking passwords, payment cards, Binance API credentials, wallet seed phrases, or private keys, and never initiates, signs, or executes cryptocurrency transactions on a customer's behalf.
